通话录音助手(基本上可以兼容绝大多数软件) 
现在的手机都可以自动录音各种语音通话,电脑却没有,就搞了一个 
不管是聊天作为记录还是 有什么事情没听清没记住,到时候回放听听都行

全部的更新日志可以看提交记录,比较详细

代码仅供学习使用，没法直接运行是因为涉及到另一个项目的公用代码
那一部分只是网络验证系统的代码，不会影响主体功能的完整性
